## 🚀 Key Features

- 🧠 **Deep Neural Intrusion Detection**: Multi-layer perceptron & Convolutional Neural Nets for packet anomaly analysis.
- ⚡ **Sub-Second Threat Classification**: Classifies DDoS, SQL Injection, XSS, and Malware payloads in real-time.
- 📊 **Security Telemetry Visualizer**: Interactive SOC dashboard mapping attack vectors and intrusion origin points.
- 🔒 **Privacy-Preserving Telemetry**: Zero-disk buffer processing for sensitive network payload analysis.
